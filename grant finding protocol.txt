**Version:** 1.0  
**Status:** Active  
**Owner:** Grant Manager

## Why This Document Exists

The Grant Manager tool tracks and manages applications. It does NOT reliably discover grants — AI cannot generate accurate, working application links from memory. This protocol defines how Claude is used *externally* to find real, verified grants, and how that information flows into the tool.

## Part 2: Grant Discovery — The Right Way

### The Core Rule
**Never trust a grant link Claude generates from memory.** Claude's training data has a cutoff and grant portals change frequently. Every grant must be verified with a live web search before being added to the tool.

### Session Setup (Start Every Research Session With This)

Paste this into Claude at the start of any grant research session:

```
You are a grant researcher for Sprout Society, a mental health peer support 
nonprofit in Brooklyn, NY (EIN: 83-1298420). 

Your job today is to find REAL, VERIFIED grant opportunities with WORKING 
APPLICATION LINKS. 

RULES FOR THIS SESSION:
1. Use web search for EVERY grant you recommend — do not generate links from memory
2. For each grant, search for and verify: (a) the funder still offers this program, 
   (b) the current application portal URL, (c) the current deadline
3. If you cannot find a working application link via search, say so — do not guess
4. Mark confidence: HIGH (verified via live search), MEDIUM (funder page found, 
   application details unclear), LOW (cannot verify — do not include)
5. Only return HIGH and MEDIUM confidence grants

Format each result exactly like this:
---
GRANT NAME: [Full program name]
FUNDER: [Organization name]
FUNDER WEBSITE: [Main org URL — verified]
APPLICATION URL: [Direct link to application page or portal — verified via search]
DEADLINE: [Specific date OR "Rolling" OR "TBD — check [URL]"]
AMOUNT: [Range or max award]
ELIGIBILITY: [Key requirements in 2-3 sentences]
FIT FOR SPROUT SOCIETY: [Why this is a good match — be specific]
CONFIDENCE: HIGH / MEDIUM
VERIFICATION NOTE: [What you searched and found to confirm this is real]
---
```

## Part 3: Verifying a Grant Before Adding to the Tool

Before clicking "Add to My Applications" in the Grant Manager, complete this checklist:

**Step 1 — Verify the funder page exists**
- Go to the funder's main website
- Confirm they have an active grantmaking program

**Step 2 — Verify the application URL**
- Click the application link
- Confirm it loads and is the current cycle (not a past year's archived RFP)
- Check for a login/portal requirement — note this

**Step 3 — Confirm the deadline**
- Deadlines on Claude's output may be estimates — find the official deadline on the funder's site
- Check if the cycle is open or if it has a LOI (Letter of Intent) step first

**Step 4 — Check eligibility fast**
- Geographic restrictions (NYC only? National?)
- Organizational age requirements (some require 3+ years)
- Budget size thresholds
- Program type restrictions (clinical vs. peer/community)

**Step 5 — Add verified data to the tool**
- Use the URL Import feature in Grant Manager with the verified application URL
- Manually correct any fields the AI got wrong during import
- Set the verified deadline
- Add a note: "Verified [date] — link confirmed working"

## Part 4: Application Workflow

Once a grant is verified and added to the tool, follow this process:

### Phase 1: Research (Week 1–2 Before Writing)

**Claude prompt for funder research:**
```
I'm applying to [GRANT NAME] from [FUNDER]. Help me research this funder.

1. What are their stated funding priorities for this cycle?
2. Who have they funded in the past that is similar to Sprout Society?
3. What language/framing do they respond to?
4. What should I emphasize vs. downplay about Sprout Society?
5. Are there any red flags or misalignment I should know about?

Search their website and any public 990s or press releases you can find.
```

**Deliverables to save in Grant Manager → Strategy Library:**
- Funder profile (1 page)
- Alignment analysis
- Language guide (words/phrases they use that we should mirror)

### Phase 2: Drafting (Week 2–3)

**Claude prompt for narrative drafting:**
```
Help me draft the [SECTION NAME] section for the [GRANT NAME] application.

Grant requirements: [paste the exact prompt from the application]
Word/character limit: [exact limit]
Funder priorities: [paste your research from Phase 1]

About Sprout Society's relevant work:
[paste any specific program stats, stories, or outcomes relevant to this section]

Draft this section to:
1. Open with a specific, human story or statistic
2. Connect our work directly to the funder's stated priorities
3. Use their language/framing (see funder profile)
4. End with a clear ask
5. Stay within the word limit
```

**After Claude drafts:**
- Paste into Grant Manager → Grant Detail → Application tab
- Note the word count
- Mark the todo "First draft complete"

### Phase 3: Review (3–5 Days Before Deadline)

**Claude prompt for application review:**
```
Please review this grant application section for [FUNDER NAME].

[Paste the draft]

Check for:
1. Does it directly answer what they asked?
2. Is the language aligned with the funder's priorities?
3. Are there any claims that need evidence/data to back them up?
4. Is the ask clear and specific?
5. What's the weakest sentence — rewrite it
6. Does it stay within [word limit]?

Be direct. Tell me what's weak, not just what's strong.
```

### Phase 4: Submission

- Submit via the verified application portal
- Screenshot or PDF the confirmation
- Update status in Grant Manager → "Submitted"
- Set a calendar reminder for the decision date
- If decision date isn't given, set a 90-day follow-up reminder

### Phase 5: Post-Award (If Funded)

- Log the award amount and date in Grant Manager
- Immediately note the **reporting deadline** in the tool (usually 6–12 months post-award)
- Send a thank-you note within 48 hours
- Add funder to relationship tracker with notes

## Part 5: Repeatable Grant Research Sessions

Run one of these sessions weekly or bi-weekly:

### Session Type A: New Grant Discovery (60 min)
1. Start Claude with the session setup prompt (Part 2)
2. Run 2–3 category searches from the Research Prompts list
3. Verify each result (Part 3 checklist)
4. Add verified grants to the tool
5. Goal: 3–5 new verified grants added per session

### Session Type B: Application Sprint (2–3 hours)
1. Pick one grant in the tool with status "In Progress"
2. Run the funder research prompt if not done
3. Draft each section using Claude
4. Paste drafts into the tool's application tab
5. Goal: Complete one full draft application per sprint

### Session Type C: Pipeline Review (30 min)
1. Open Grant Manager Dashboard
2. Check upcoming deadlines — anything due in under 14 days?
3. Check todo completion on in-progress applications
4. Identify any grants that have gone stale (no activity in 2+ weeks)
5. Goal: Nothing falls through the cracks

## Part 7: What Claude Cannot Do (Important Limits)

| Task | Claude Can Do? | Alternative |
|------|---------------|-------------|
| Find grant names and funders | Yes — with web search | — |
| Generate working application links from memory | NO — links will be wrong | Use web search, verify manually |
| Predict exact deadlines without searching | NO — cycles change | Always verify on funder's site |
| Access paywalled databases (Foundation Directory, Instrumentl) | NO | Subscribe to these separately |
| Submit applications | NO | Manual submission required |

| Draft narratives tailored to Sprout Society | YES — excellent at this | — |
